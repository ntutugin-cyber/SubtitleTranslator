# SubtitleTranslator

Программа на C# для автоматического перевода субтитров.

## 🚀 Возможности
* Автоматический перевод файлов субтитров.
* Поддержка интеграции с сервером на Python (`server.py`).
* Удобный графический интерфейс (WPF/XAML).

## 🛠️ Технологии
* **Язык:** C# (.NET)
* **Интерфейс:** WPF
* **Дополнительно:** Python (для серверной части перевода)

## 💻 Как запустить проект
1. Скачайте и запустите VibeVoice ASR (например отсюда: [VibeVoice_ASR_portable_ru](https://github.com/timoncool/VibeVoice_ASR_portable_ru))
2. Склонируйте этот репозиторий и запустите программу
3. Запустите также серверный скрипт `python.exe server.py` установив предварительно все необходимые библиотеки, которые он запросит
4. Выберите видео для транскрибации (желаетельно не больше 20 минут)
5. Транскрибируйте это видео в программе VibeVoice_ASR и получите чистый json
6. Вставьте этот чистый полученный json в первое текстовое поле во вкладке "работа с текстом"
7. Нажмите кнопку "📝 В субтитры (SRT)" или "📄 В текст", сырой json должен обработаться и дополниться переводом, на сервере должен сработать скрипт переводчика, этот дополненный переводами json можно сохранить и в будущем использовать в этой программе дабы заново не ждать транскрибации или перевода
8. Скачайте и запустите программу Higgs-Ultimate (например отсюда: [Higgs-Ultimate](https://github.com/timoncool/Higgs-Ultimate)), установите и скачайте на ней все необходимые библиотеки и нейросетевые модели, добавьте свои голоса во вкладке "Галерея голосов" и попробуйте на выбранном голосе запустить и озвучить что нибудь в тестовом режиме
9. Перейдите во вкладку "API" в скачанной программе Higgs-Ultimate и запустите локальный API
10. Скопируйте и вставьте хост сразу с портом через двоеточие (например "http://127.0.0.1:7077") и ключ в аналогичные поля в моей программе
11. Можете нажать кнопку "🔍 Проверить сервер", если всё хорошо то в логе отобразится это
12. Разверните Expander "Озвучка через Higgs TTS Studio" и нажмите кнопку "Обновить список" чтобы загрузить список голосов (эта кнопка может не сработать с первого раза, сервер не сразу отдаёт голоса)
13. Нажмите кнопку "Расп. суб.", чтобы распарсить субтитры и распределить их по случайным голосам
14. Откройте вкладку "📤 Таблица голосов", там можно выбрать для каждого говорящего свой голос правой кнопкой мыши при выбранном голосе наверху в Combobox
15. Нажмите кнопку "Озв. вид." и выберите ранее транскрибированное видео, должна пройти озвучка с переводом видео на русский язык установленными голосами
